LAB 8 - SCD TYPE 2 OUTPUT

Target:
lab_db.gold_dim_customers

Operation:
MERGE INTO

When a current customer record matches:
is_current changes to false
end_date is set to current_date()

When a customer record does not match:
a new record is inserted
is_current = true
effective_date = current_date()
end_date = NULL

Expected verification:
Updated customer information produces an expired historical record and a new active record.
